## Selected Engineering Projects

### [STM32F446 Bare-Metal Firmware](https://github.com/tonimatutinovic/stm32f446-baremetal-firmware)

**C · STM32F446RE · ARM Cortex-M4 · CMSIS**

*Active development*

Register-level firmware development with custom GPIO, EXTI, UART, timer, and ADC drivers, complemented by LED and CLI abstraction modules.

- GPIO external interrupt handling (EXTI)
- Interrupt-driven UART with RX/TX ring buffers
- Non-blocking communication and error handling
- Incremental development and hardware validation
- SPI and I2C drivers planned

### Automotive ECU – Real-Time Sensor Fault Diagnostics

**STM32 · FreeRTOS · CAN · Automotive diagnostics**

*Completed Master's thesis · Source code not currently public*

Design, implementation, and experimental evaluation of an ECU prototype for real-time sensor fault diagnostics in automotive embedded systems.

- RTOS-based sensor acquisition and processing
- Fault detection, classification, and diagnostic state machines
- CAN-based diagnostic communication
- Fault injection and response-time evaluation

### [myDHT – Open-Source Sensor Library](https://github.com/tonimatutinovic/myDHT)

**C++ · Library architecture · Bit-banging**

*Published open-source library · Available through the Arduino Library Manager*

A two-layer Arduino library for DHT11/DHT22 sensors, combining an accessible high-level API with advanced protocol control and diagnostic capabilities.

- Custom timing-sensitive protocol implementation
- Shared core with two API abstraction levels
- Asynchronous operation and error diagnostics
- Cross-platform build automation and technical documentation

### [Automotive Parking Assist System](https://github.com/tonimatutinovic/parking-assist-system)

**C++ · Arduino · Sensor processing**

*Functional prototype · Further development planned*

Dual-sensor parking assistance prototype featuring distance filtering, state-based control, adaptive warnings, and sensor fault detection.

Planned evolution towards STM32, DMA, interrupt-driven processing, and FreeRTOS.
